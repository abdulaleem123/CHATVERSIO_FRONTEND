# Component map

All generated sections live in `components/`. The generator's shared helpers provide typography, images, arrows and links. CSS classes and IDs are part of the behavior contract.

| Component | Source function / DOM | Behavior |
| --- | --- | --- |
| Header and mobile navigation | `nav(path)` / `.masthead`, `#main-nav` | Opens/closes, closes on links, outside click and Escape; current-route indicator |
| Hero portraits | `hero()` / `.cast-stage` | Chat / Sales / Voice selection and pointer response |
| Live 3D scene | `scene/hero.js` / `.hero-3d` | Four GLB models, lighting, entrance, parallax and selected-agent transitions |
| Headset turntable | `.turntable` / `setupTurntable` | Drag, previous/next, keyboard arrows and Home; 40-image fallback |
| Motion control | `motion_button()` / `.motion` | Persistent preference; respects OS reduced-motion setting |
| Showreel | `film()` / `#showreel` | Native modal, video playback, sound switch, transcript, captions and Escape |
| Agent cards | `solution_wall()` / `.cast-posters` | Links to the three main service pages |
| Workflow demonstration | `story()` / `.story`, `#story-data` | Four industries, three scenes, callback/booking outcomes, audio and prefilled enquiry links |
| Supporting-service directory | `directory()` / `.directory` | Five category filters, visible counts, all 15 supporting-service links |
| Integration illustration | `integrations()` / `#integration-data` | Twelve selectable tools; animated cable and input/output labels |
| Delivery process | `process()` / `.process-book` | Six accessible details accordions, one open at a time |
| FAQ | `questions()` / native `details` | Mouse, touch and keyboard disclosure |
| Contact form | `contact_page()` / `#brief-form` | Same fields as the original contact form; direct submit to `/api/contact` |
| Booking form | `booking_page()` / `#booking-form` | Same fields as the original schedule form (date, time, Google Meet/Zoom); direct submit to `/api/schedule` |
| Footer | `footer()` / `#footer` | Original transparent logo, links/socials, animated gradient wordmark and responsive columns |
| Service detail pages | `service_page()` / 18 slugs | Shared template populated by `services` and `PROFILES` |

`dist/studio.js` owns the original UI; `dist/integration.js` owns form delivery. The integration script does not replace the 3D or animation code. Keep the JSON data scripts generated by `story()` and `integrations()` with their sections.

All component partials expect the same global CSS and document shell. They are integration source, not independently isolated web components. For a framework port, replace document-wide listeners with scoped hooks and dispose each WebGL renderer, observer and animation loop on unmount.
